## What I'm Building

**[AART — Autonomous API Red Teaming]([https://github.com/yourusername/aart](https://github.com/mahmad0610/aart-cyber-shield))**
> A multi-agent security scanning platform that does what manual pen-testing can't scale to.

Static analysis → dynamic testing → sandbox exploit confirmation → LLM-assisted patch generation — all wired together in a LangGraph pipeline with a hardened Docker sandbox on Oracle OCI. Supabase backend with atomic writes. Multi-model Groq LLM cascade for confidence-tiered reporting.

**[Sehatly — AI Clinical Automation Platform]([https://github.com/yourusername/sehatly](https://github.com/mahmad0610/Sehatly))**
> Making every doctor superhuman — without taking control away from the clinician.

End-to-end multi-agent system automating the full care workflow: symptom triage → smart booking → 45-second pre-consultation briefs → AI-drafted care plans with drug interaction checks → medication adherence monitoring. 7 specialized AI agents (Triage, Booking, Prep, Plan, Track, Learn, Orchestrator) coordinated via a central orchestrator. Stack: FastAPI microservices, PostgreSQL 16 + PostGIS, Redis, RabbitMQ, Claude 4 + GPT-4 fallback, BGE-M3 embeddings, Pinecone. React Native (mobile) + React SPA (clinician web). HIPAA/FDA-ready, HL7/FHIR compatible, AWS multi-region.
